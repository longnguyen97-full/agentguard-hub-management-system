AgentGuard Control Plane Documentation

Comprehensive guide to configuring, operating, and integrating your AI agents with real-time operational safety guardrails, emergency controls, and deep tracing telemetry.

1. Operational Safety Guardrails

Emergency Kill Switch

Immediately aborts active background execution threads when an agent behaves unexpectedly. Can be triggered via the red button on the Dashboard or calling POST /api/agents/runs/{id}/kill.

Infinite Loop Guardrail

Continuously hashes and checks tool call signatures. If an agent repeats identical tool calls with the same arguments consecutively, execution is halted to prevent token burn.

Human-in-the-Loop (HITL)

Sensitive actions (database mutations, transactions, emails) trigger an automatic pause in state WAITING_APPROVAL until approved via the UI or API.

Hard Budget Guardrail

Enforces strict step limits, token thresholds, and financial limits in both USD and VND to keep AI deployment costs predictable and bounded.

2. Client SDK Quick Integration (3 Steps)

Copy agent_sdk.py into your project and stream steps into AgentGuard in real time: 

from agent_sdk import AgentTracker

# 1. Initialize tracker pointing to AgentGuard Hub
tracker = AgentTracker(endpoint="http://localhost:8000")

# 2. Register run session
session = tracker.start_run(
    agent_name="ProductionAgent",
    prompt="Query customer invoice #4088 and process refund",
    budget_usd=0.20
)

# 3. Log billable LLM thought & tool call
session.log_step(
    thought="Querying database for order details.",
    tool_name="query_invoice",
    tool_input={"invoice_id": 4088},
    tool_output={"amount": 45.0, "status": "paid"},
    tokens_used=180,
    cost_usd=0.00005,
    is_billable=True
)

# 4. Finish session
session.finish(final_output="Invoice processed successfully!")

3. REST API Quick Reference

Method Endpoint Description
POST /api/agents/run Launch standard or preset agent run
GET /api/agents/runs List all runs and current metrics
POST /api/agents/runs/{id}/kill Emergency kill switch trigger
POST /api/agents/runs/{id}/approve Resolve pending human-in-the-loop approval
GET /api/agents/stream Server-Sent Events (SSE) realtime broadcast
