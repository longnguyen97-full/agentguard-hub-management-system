AgentGuard Control Plane Documentation

Comprehensive guide to configuring, operating, and integrating your AI agents with real-time operational safety guardrails, emergency controls, and deep tracing telemetry.

1. Operational Safety Guardrails

Emergency Kill Switch

Immediately aborts active background execution threads when an agent behaves unexpectedly. Can be triggered via the red button on the Dashboard or calling POST /api/agents/runs/{id}/kill.

Infinite Loop Guardrail

Continuously hashes and checks tool call signatures. If an agent repeats identical tool calls with the same arguments consecutively, execution is halted to prevent token burn.

Human-in-the-Loop (HITL)

Sensitive actions (database mutations, transactions, emails) trigger an automatic pause in state WAITING_APPROVAL until approved via the UI or API.

Hard Budget Guardrail

Enforces strict step limits, token thresholds, and financial limits in both USD and VND to keep AI deployment costs predictable and bounded.

Manual SDK Integration

from agent_sdk import AgentTracker

# 1. Initialize tracker pointing to AgentGuard Hub (:8000)
tracker = AgentTracker(endpoint="http://localhost:8000")

# 2. Register run session with budget & step limits
session = tracker.start_run(
    agent_name="ProductionAgent",
    prompt="Query customer invoice #4088 and process refund",
    budget_usd=0.20,
    max_steps=10
)

# 3. Log billable LLM thought & tool call
session.log_step(
    thought="Querying database for order details.",
    tool_name="query_invoice",
    tool_input={"invoice_id": 4088},
    tool_output={"amount": 45.0, "status": "paid"},
    tokens_used=180,
    cost_usd=0.00005,
    is_billable=True
)

# 4. Finish session safely
session.finish(final_output="Invoice processed successfully!")
import { AgentHubClient } from '@/lib/agentHubClient';

// 1. Initialize TypeScript client (points to AGENT_HUB_URL or :8000)
const hub = new AgentHubClient(process.env.AGENT_HUB_URL || 'http://localhost:8000');

// 2. Start session
const run = await hub.startRun({
  agent_name: 'NextJsChatBot',
  prompt: 'Calculate user shipping costs and confirm checkout',
  budget_usd: 0.15,
  max_steps: 8
});

// 3. Log step with fail-open safety
await hub.logStep(run.run_id, {
  step_number: 1,
  thought: 'Executing tax & shipping calculation via local microservice',
  tool_name: 'calc_shipping',
  tool_input: { zip: '70000', weight_kg: 2.5 },
  tool_output: { fee_vnd: 35000 },
  is_billable: false // Deterministic local code = $0.00
});

// 4. Conclude session
await hub.finishRun(run.run_id, { status: 'COMPLETED', final_output: 'Order confirmed' });

3. REST API Quick Reference

Method Endpoint Description
POST /api/agents/run Launch standard or preset agent run
GET /api/agents/runs List all runs and current metrics
POST /api/agents/runs/{id}/kill Emergency kill switch trigger
POST /api/agents/runs/{id}/approve Resolve pending human-in-the-loop approval
GET /api/agents/stream Server-Sent Events (SSE) realtime broadcast
GET /api/agents/data/stats Storage analytics for Dashboard SQLite & Langfuse
POST /api/agents/data/backup Create timestamped backup archive (.zip)
POST /api/agents/data/restore Restore state from backup with automated rollback
POST /api/agents/data/reset Safe data purge (Dashboard / Langfuse / All)

Crucial Integration Notes & Troubleshooting (Lưu Ý Quan Trọng)

Tiếng Việt UTF-8 Trên Windows (Tránh lỗi dấu ?)

Windows mặc định dùng cp1252 làm biến dạng dấu tiếng Việt thành ? và �. Trong client Python, thêm import os; os.environ["PYTHONUTF8"] = "1" ở dòng đầu và mở file bằng encoding="utf-8". Trong PowerShell, gõ chcp 65001.

Luôn Khởi Chạy Bằng uv run

Tránh lỗi ModuleNotFoundError: No module named 'fastapi' bằng cách khởi động qua uv run run.py hoặc uv run agent-hub thay vì gọi python hệ thống chưa kích hoạt venv.

Tách Đoạn Tốn Phí vs Miễn Phí (0đ)

Chỉ đặt is_billable: true cho các bước gọi LLM tốn token API. Đặt is_billable: false (0đ) cho code Python, quét Regex, truy vấn Database nội bộ để báo cáo tài chính chuẩn xác.

Phê Duyệt An Toàn (Human-in-the-Loop)

Khai báo các tool nhạy cảm (cập nhật DB, thanh toán, gửi email) vào require_approval_tools để Agent tự động dừng ở trạng thái WAITING_APPROVAL chờ duyệt.
